# Spec audit

1. Call `spec_status`, `spec_context`, and `spec_next`.
2. Run `spec_validate`.
3. Group findings by consequence for humans.
4. List blockers, open questions, missing evidence, and approvals to renew.
5. Keep technical IDs behind an explicit technical-details request.
6. Do not claim verification without a checker result.
